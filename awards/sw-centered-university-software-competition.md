# SW중심대학 Software Application Competition - Excellence Award

Received the 자립상 (English name used on LinkedIn, resumes, and the portfolio website:
Excellence Award) with team BLUE SKY at Woosong University's SW중심대학 (Software-Centered
University) competition.

The awarded project was a software solution for predicting water-treatment plant odor levels from
multivariate time-series data using machine learning and deep learning methods.

LinkedIn notes certificate number 2023-980, a prize of 1,000,000 KRW, and an issue date of
2023-12-08.

## Certificate

Scan: [certificates/sw-centered-university-software-competition.pdf](certificates/sw-centered-university-software-competition.pdf)

- Award name: **자립상** (自立賞). It is named after 자립 (self-reliance), part of Woosong
  University's motto. LinkedIn spells it "자림상", which is a typo. The certificate gives the reason
  as 우수한 성적 (excellent results), which is where the English name "Excellence Award" comes from.
- Competition name on the certificate: SW중심대학 2023년도 하반기 SW창의융합 경진대회 (Software-Centered
  University SW Creative Convergence Competition, second half of 2023).
- Certificate 2023-980호, dated 2023-12-08, from the President of Woosong University (오덕성).
- Recipients listed: 안시은, Kasimov Azizjon, 조민우, Victor Opaleke, and Sukhrob Ikromov. The team
  name BLUE SKY is not printed on this certificate; it is on the LINC 3.0 certificate.
- The portfolio website shows this certificate (`public/certificates/software-competition-award.jpg`
  in the website repo) and uses 자립상 on its Korean pages.

## LinkedIn Detail Notes

- Competition held at Woosong University in Daejeon, South Korea in 2023.

- Team BLUE SKY's project predicted odor levels in water treatment plants, using multivariate
