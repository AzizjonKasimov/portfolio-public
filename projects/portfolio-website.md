# Portfolio Website

**June 2025 - Present | Personal project | Live at azizjonkasimov.github.io**

Azizjon's public portfolio site. On 2026-09-23 it was rebuilt as a fast static site (Vite,
GitHub Pages, deployed by GitHub Actions) with a homepage and four case studies: AI semantic
search, the serverless AWS data pipeline, solar forecasting and anomaly-detection MLOps, and the
LangGraph catalog-data agent. On 2026-09-29 two personal-app case studies were added: the
Expenses AI expense tracker (`/work/expense-tracker/`) and Network App (`/work/network-app/`).
The site may be listed in resumes and applications next to
LinkedIn and GitHub; every current resume links it. LinkedIn Featured links to the homepage and the
semantic-search case study (the solar-MLOps link was removed on 2026-09-25), and the LinkedIn
project entry is "Portfolio website with production case studies" (`profile/linkedin.md`).

## History

- June 2025 - September 2026: as the "Resume Chatbot Website", an LLM chatbot answered
  visitors' questions about Azizjon, using
  his professional experience as context (Django/Groq backend on Render's free tier).
- July 2026: marked as under maintenance and kept off resumes because the site was not working
  well.
- 2026-09-23: the chatbot was removed. The free-tier backend took about 42 seconds to answer
  the first request, visitors saw no portfolio content until they typed a question, and
  recruiters skim rather than chat. The backend repository is retired.
