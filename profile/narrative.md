# Personal Values, Motivation & Story

Background material for bios, cover letters, "about me" sections, and personal statements.

## Engineering principles

Four principles from Azizjon's own LinkedIn posts, each backed by work in this repo. They have
anchored the LinkedIn About since 2026-09-25 (`profile/linkedin.md`).

1. **Use AI for judgment calls, and code for anything that must be exact.** In the G-Man search,
   entity recognition and structured filters do the precise matching, and the LLM cleans up the
   query and re-ranks. The expense app once counted a bank balance as income, so code now reads
   the numbers and the AI only picks the category.
2. **Better input beats a better prompt.** A part-name alias layer ("headlight" to "Head Lamp
   Assembly") raised search recall. In the expense app, no prompt could label
   `쿠팡(쿠페이)_KICC`; giving the model real product names from receipt emails could.
3. **Measure before you claim.** The automated accuracy suite (accuracy@1/@3, precision, recall,
   F1, confusion matrix) came before any quoted number. At Recs Innovation, anomaly-detection
   precision rose about 35% and recall about 37%, one measured change at a time.
4. **Ship small, then improve.** Docker and GitHub Actions cut deploys from 3 hours to 15
   minutes. The expense tracker began as a two-day Telegram bot and is now an Android app in
   daily use.
